# 对话核对助手（chat-verify-helper）

客服对话页上的悬浮面板：自动读取访客在对话里提供的**帐号、银行卡号、姓名、钱包地址**，集中显示，可一键复制，也可点一下跳回原消息。

资料只在当前页面的内存里处理，**不上传、不保存**。

## 功能

- 自动读取当前对话，分出访客和客服的消息，只从访客消息里提取资料
- 参考客服上一句问了什么（帐号、姓名、卡号、钱包…），判断访客回答的是哪一项
- 识别项目
  - 帐号（含从访客名里提取，例如 `abc123_xxx` → `abc123`）
  - 银行卡号（15～19 位，用 Luhn 校验位检查是否打错）
  - 姓名（含少数民族「·」分隔的姓名）
  - 钱包地址（TRC20、ERC20/BEP20、BTC）
- 标题栏显示访客身份（访客／会员／代理）
- 标签提示
  - 「推测」：客服没有明确问到，按格式推测的
  - 「校验未通过·可能打错」：卡号校验位不符
  - 「已去空格」：访客在帐号中间多打了空格，已自动合并
- 每个访客的资料分开保存，切换对话不会混在一起
- 面板可拖动、可收起，位置会记住

## 安装

### 方式一：Chrome 扩充功能

1. 打开 `chrome://extensions`
2. 右上角打开「开发人员模式」
3. 点「载入未封装项目」，选这个文件夹

客服系统还有其他网址时，修改 `manifest.json` 里的 `"matches"`。

### 方式二：Tampermonkey

新建脚本，把 `content.js` 整段贴上后保存。
客服系统还有其他网址时，在文件头照样加一行 `// @match *://其他网址/*`。

## 使用

打开客服系统，进入任一对话，右侧会出现「核对信息」面板。

| 操作 | 效果 |
| --- | --- |
| 单击数值 | 跳到原消息，并用橘黄色外框标出来 |
| 双击数值，或按「复制」 | 复制这一项 |
| 「复制全部」 | 按「访客／帐号／卡号／姓名／钱包地址／身份」的格式一次复制 |
| `×` | 移除认错的项目；「恢复已移除」可以复原 |
| `–` | 收起成小按钮，再点一下展开 |

## 识别方式

- 消息标题格式为「发送者 于 YYYY/MM/DD HH:MM:SS」，标题后面紧接的就是消息内容
- 名字是 `guest_数字` 的一定是访客；其他人按标题在消息列表的左边还是右边来判断（用 guest 访客校准，默认访客在左边）
- 客服问到的项目标为确定；没问到、但格式符合的标为「推测」
- 已经被页面卸载的旧消息，会保留之前读到的结果

## 隐私

- 脚本不发出任何网络请求
- 读到的资料只存在当前分页的内存里，关闭或刷新页面就清空
- `localStorage` 只记面板位置（`cvh.pos`）和是否收起（`cvh.min`）

## 排查问题

在客服页面按 F12 打开开发者工具，在 Console 输入：

```js
__cvhDebug()
```

可以看到每条消息被判成访客还是客服、位置在哪一边、内容是什么。
如果对话在 iframe 里，先在 Console 左上角的下拉选单切换到那个 frame。
